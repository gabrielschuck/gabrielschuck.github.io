Política de Privacidade do Gabibot

Última atualização: 31 de outubro de 2026.

O Gabibot é uma ferramenta pessoal de Gabriel Schuck, usada somente por ele, na própria conta. Não há cadastro de outras pessoas.

Dados acessados

Com a autorização do Gabriel, o Gabibot usa as APIs oficiais do Google para acessar o canal dele no YouTube: ler os comentários públicos dos vídeos, publicar as respostas e consultar as estatísticas do próprio canal. O mesmo vale para as páginas e contas dele em outras redes sociais, pelas APIs oficiais de cada uma.

Como os dados são usados

Os dados servem somente para organizar os comentários, sugerir respostas para o Gabriel revisar e acompanhar o desempenho dos vídeos dele. Eles não são vendidos, não são usados para publicidade e não são compartilhados para outros fins.

Onde os dados ficam

Os dados ficam guardados no computador do Gabriel. Para escrever sugestões de resposta, o texto de um comentário pode ser processado por um modelo de inteligência artificial que roda nesse computador ou por um serviço de inteligência artificial escolhido por ele. Avisos sobre novos comentários podem ser enviados ao próprio Gabriel pelo Telegram.

Uso de dados das APIs do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como remover o acesso

O acesso pode ser cancelado a qualquer momento em permissões da Conta do Google.

Contato

Dúvidas e pedidos sobre esta política podem ser enviados pela seção de avisos deste site no GitHub.
